# Tecnología que protege cada gota
Actualmente nuestro estado atraviesa un problema con la pureza del agua potable, nuestro proyecto se centra en poder aplicar la electrónica y programación para desarrollar dispositivos e interfaces que detecten anomalías en el agua que se distribuye en nuestra ciudad y estado, aportando bienestar a las viviendas detectando turbidez, pH, TDS y temperatura del agua potable..
